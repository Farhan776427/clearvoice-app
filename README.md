# clearvoice-app
📞 Call Mode: कॉल के दौरान आपकी आवाज़ साफ़ करे और आसपास का ट्रैफिक/हवा का शोर हटाए। 🎮 Gaming &amp; Streaming Mode: गेमिंग वॉइस चैट (BGMI, Free Fire, Discord) के लिए लो-लेटेंसी (Low Latency) म्यूटिंग। 🎧 Listen / Isolation Mode: अगर आप सिर्फ गाना सुन रहे हैं या शांत रहना चाहते हैं, तो बाहर की आवाज़ों को काटना।
